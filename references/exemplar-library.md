# 优秀提示词范例库

本文件用于学习用户认可的语言密度、连续性与控制方式。使用范例时，先读“可泛化规律”和“不可泛化内容”，不要机械复制人物、场景、动作或情绪。

### 可泛化规律

- 将推进、横漂和高度起伏融合为一条手持曲线，并明确主次。
- 贴近面部后用克制侧漂管理距离，不无因停住或反向。
- 景别越近，材质细节越具体；拉回后焦点回到姿态与空间。
- 眼神随镜头角度转动，表演以视线、眨眼和呼吸为主。
- 外部声响触发察觉、转头、确认、放松和侧脸定格。
- 风、树叶、发丝、斑驳光影和环境声共同变化。
- 声音随镜头距离和环境风势改变强弱。

### 不可泛化内容

- 具体女性身份、白色上衣、刘海和肤色。
- 户外树荫、鸟鸣和左侧画外动静。
- 拨头发、耸肩和侧脸警觉的具体故事。
- 固定的自拍构图和无对白设定。

### 对Skill的实际增量

- 建立“主运动趋势＋人体来源微扰”的手持曲线模型。
- 建立距离驱动细节和动态声景规则。
- 将心理状态改写为可观察的刺激—反应—恢复过程。

### 可泛化规律

- 先分层锁定核心设定、设备、人物、场景、动作时间轴和反向限制。
- 手机原生质感由手持曲线、曝光浮动、对焦呼吸、暗光噪点和较深景深共同形成。
- 开门声是心理与动作触发点，转头、目光锁定、走近、接触、耳语形成因果链。
- POV摄影者的身体必须有限入画，手部要有来源、左右归属、接触点、受力和退出状态。
- 亲密接触需要成年关系、自愿回应、重心与衣料反馈。
- 对白需要说话距离、气声、口型、尾音和说后眼神终态。
- 环境声、接触声、呼吸和对白按镜头距离动态分层。
- 手机实拍模式应主动排除强浅景深、商业布光与重度精修。

### 冲突与高风险点

- 前文为“长直发、自然中分”，后文为“长卷发、偏分”，属于发型不变量冲突。最终提示词必须按参考图或全局优先级统一。
- 摄影者双手同时勾领口与扶腰，同时还要维持手机POV，属于身体逻辑和手部生成高风险。稳定写法改为单手轻触肩臂或腰侧，另一只手默认持机且不入画。
- “领口拉近”和“肩头滑落”具有不必要的衣物风险。保留在原始范例中，但不泛化为默认动作。
- 10秒内同时包含走近、双手接触、回抱、衣物变化、眼神游移、耳语和再次靠近，生成压力较高；稳定版应减少一个接触动作或固定摄影机距离。

### 不可泛化内容

- 具体女性外貌、浅粉针织上衣、短裙和项链。
- 玄关与客厅、等待归家的恋爱故事。
- 勾领口、扶腰、环颈、衣物滑落和具体台词。
- 10秒固定分配和参考图特定身份。

### 对Skill的实际增量

- 新增手机原生实拍、POV有限入画、成年克制亲密互动和对白事件模型。
- 新增设备、发型、双手接触和衣物状态的冲突检查。
- 明确长提示词可以保留，但必须用高风险稳定版控制并发动作。

- **用户实测有效**：证明该写法在用户实际工作流中产生过良好结果，但不自动升级为所有模型的硬规则。
- **平台官方建议**：可用于确认格式或模型关系，仍需判断是否适合跨模型默认输出。
- **创作方法参考**：用于组织思路和补漏，不作为平台能力声明。
