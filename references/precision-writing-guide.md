# 人物 POV 手机实拍与对白精准写作指南

仅在任务包含手机原生实拍、人物微表演、POV、成年亲密互动或对白时读取。

## 高精度模式的摄影询问

用户要求“详细、完整、尽可能详细、导演级”等高精度提示词，但没有明确摄影效果时，先问视觉结果，不先问设备数值。问题应一次只解决会改变方案的选择，例如：

- 希望空间显得开阔、有纵深，还是贴近、压迫？
- 希望背景清楚可辨，还是主体突出、背景柔化？
- 希望真实手持、轻微呼吸感，还是稳定器式平稳？
- 希望纪实生活感，还是精致电影摄影感？

根据答案推导焦段类别、机位距离、光圈/景深、对焦和稳定方式。若参考图或设备模式已经给出明确答案，不重复询问。用户无法判断时，用可见效果说明推荐选项并采用推荐值。

具体摄影机品牌、镜头型号和数值不是“详细”的必要条件；只有它们能约束真实成像结果时才加入。禁止同时写手机主摄原生视频与电影机大光圈奶油虚化等互斥设定。

## 手机原生实拍

把手机特征写成可见行为，不写空泛的“手机感”：

- 步行推进产生低频、小幅垂直起伏；握持修正产生不规则轻微横漂。
- 进入暗区或靠近面部时，自动曝光轻微补偿；变化连续，不突然闪白。
- 面部距离快速改变时允许一次短促对焦呼吸，随后重新锁定眼睛。
- 暗光保留轻微亮度噪点和细节软化，但脸部结构仍稳定。
- 手机主摄通常保持较深景深，背景不应被抹成商业人像式奶油虚化。

## 手持曲线写法

推荐公式：

`主趋势 + 人体来源的微扰 + 距离管理 + 构图修正 + 终点`

示例结构：缓慢均匀推进是主趋势；步伐带来极小高度起伏，握持带来轻微横漂；贴近后沿脸侧小幅漂移维持距离；随后随人物动作自然拉回；最终在侧脸构图中停止。

“自然晃动”必须有幅度边界。禁止把抖动、漂移、升降和环绕全部写成同等强度。

## 微表演

眼神优先于表情标签：

- 写视线从哪里移动到哪里、速度如何、是否停留。
- 眨眼写次数和触发位置，不要全程频繁眨眼。
- 情绪变化先出现在眼神、呼吸和嘴角张力，再传到头部与身体。
- 惊觉、害羞、放松等状态都要有恢复或定格，不突然换脸。

## POV有限入画

单手模板：

`摄影者的[左/右]手从画面[方向]进入 → 手指姿态 → 接触[准确部位/物体] → 使用[轻/中]力度 → 对方或物体产生[反馈] → 手停留/松开/退出`

不要用“你伸手”代替空间描述。镜头本身与手来自同一身体，手臂动作会带来轻微构图补偿，但不能造成无规律震动。

## 成年亲密互动

- 首先明确双方成年与关系语境。
- 接触前出现可观察的靠近、停顿、抬手或目光确认。
- 对方以姿态放松、主动靠近、回抱或视线回应表达自愿。
- 接触造成的重心、头发和衣料反馈必须轻微且符合重力。
- 默认不强调领口拉扯、衣物滑落、胸腿局部或身体曲线。
- 若用户原文包含高风险动作，保留叙事意图，改为更稳定克制的肩、臂、腰侧轻触；必要时说明调整。

## 对白同步

对白前：进入距离、面部朝向听者、一次自然吸气。

对白中：嘴唇运动与音节连续，音量符合距离；耳语保留气流和近讲感，但不过度ASMR化。

对白后：嘴唇停止，呼吸释放，眼神和姿态形成终态。尾音上扬、拖长或收紧必须与情绪一致。

## 动态声景

为声音写包络：

`何时开始 → 如何增强 → 何时达到主观最近 → 如何衰减 → 结束后留下什么底噪`

动作声只在真实接触时出现。门锁、衣料、发丝、脚步、呼吸和对白不能同时抢占前景；每个语义节拍只突出一到两个近景声音。
