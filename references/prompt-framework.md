## 1. 输入模式与工作强度

在写正文前先完成内部设计卡：

| 字段 | 可选答案 |
|---|---|
| 输入模式 | 无参考、首帧、首尾帧、尾帧、多模态参考、源视频编辑/续写 |
| 拍摄组织 | 一镜到底、允许切镜、分段独立生成、动作匹配 |
| 成像模式 | 电影摄影、手机原生、纪录片、无人机、监控、动画或其他 |
| 时长/画幅 | 用户指定；未指定且会改变方案时询问 |
| 精度 | 常规、高精度 |
| 唯一主事件 | 一句话说清谁因何完成什么，最终停在哪里 |
| 最大风险 | 身份、结构、肢体、交接、并发动作、运镜、文字或声音 |

常规模式只写决定成片的参数。高精度模式允许充分展开，但不得用同义形容词制造虚假精度。

## 2. 三层设计法

### 静态视觉层

#### 时间

- 年代只在服装、建筑、商品、交通工具或影像质感需要历史约束时写。
- 季节与时刻必须通过植被、衣着、光线、天气或生活活动体现。

#### 主体

- 人物：成年状态、身份、年龄感、脸型、五官、肤质、发型、体态、服装、配饰、初始姿势。
- 生物：种类、品种、体型、毛色、特殊结构、初始动作。
- 物品：类型、数量、轮廓、尺寸、颜色、材质、表面痕迹、部件与开口方向。
- 建筑/机械/载具：比例、重复构件数量、接口、承重关系、运动部件、结构不可变量。

只锁定能跨帧识别或影响动作的特征。不要把所有微小外貌字段都升级为硬约束。

#### 场景

描述空间层级、地面、背景、关键陈设、动线、遮挡、天气与真实生活痕迹。给人物、载具和摄影机保留可通行空间。

#### 摄影

优先描述可见结果：

- 构图与主体占比；
- 机位高度、角度和朝向；
- 广角、标准或长焦形成的透视结果；
- 焦点落点与景深范围；
- 光源位置、软硬、色温和阴影方向；
- 色彩关系与介质质感。

摄影机型号、具体毫米数与光圈值只有在能减少歧义时写。手机原生、无人机、监控与纪录片模式不得被电影机参数污染。

### 动态连续层

每个关键动作填写：

| 状态 | 要回答的问题 |
|---|---|
| 初始 | 人、物、摄影机分别在哪里，当前是否接触？ |
| 触发 | 哪个可见或可听事件促使动作开始？ |
| 准备 | 视线、重心、手势、机械锁定或动力如何先变化？ |
| 执行 | 谁/什么从哪里沿什么路径到哪里？ |
| 反馈 | 身体、道具、衣料、头发、地面、阴影和声音如何响应？ |
| 停止 | 如何减速、卸力、落稳或停止？ |
| 终态 | 左右位置、朝向、接触关系、物体状态和视线落点是什么？ |
| 接口 | 什么触发下一节拍或下一镜？ |

摄影机使用同一表格：起点、运动类型、幅度、速度、目标、构图修正、终点。手持微扰只能附着在主运动上。

### 音画同步层

| 声音层 | 书写要求 |
|---|---|
| 环境底噪 | 来源、空间大小、远近、全程是否连续 |
| 动作音 | 与接触或机械动作同步，说明材质和衰减 |
| 人物非语言声 | 呼吸、笑声、喘息等与距离和表演阶段绑定 |
| 对白/画外音 | 说话者、听者、距离、声线、口型、起止、说后状态 |
| 配乐 | 只有用户要求或叙事确实需要时加入，写乐器、速度和动态 |

声音不能只是名词清单。每个语义节拍只突出一到两个前景声音，其他声音退为底层。

## 3. 参考素材职责表

先建立内部表，再写自然语言：

| 素材 | 来源中采用什么 | 在目标视频中控制什么 | 保留强度 | 明确不采用什么 |
|---|---|---|---|---|
| 图片1 | 例如人物五官与发型 | 主角身份 | 完整保留 | 背景、文字 |
| 图片2 | 例如建筑入口结构 | 场景与构图 | 完整保留 | 路人面孔 |
| 视频1 | 例如缓慢侧向跟拍 | 运镜与节奏 | 属性迁移 | 人物、场景 |
| 音频1 | 例如低沉平稳声线 | 说话音色 | 参考而非复制 | 原台词、背景音乐 |

同一素材可以承担多个明确职责，但不能写“完全参考所有内容”。视频素材用于整段编辑、续写或时间结构时，和只借用动作/运镜是不同关系。音频必须区分直接复用原信号与只参考声线、节奏或质感。

## 4. 关键帧连接方法

### 首帧驱动

`首帧事实锚定 → 允许变化项 → 动作征兆 → 动作启动 → 连续发展 → 结果/反应 → 尾帧状态`

首帧中的身份、服装、关键物体、构图和空间关系保持稳定。不要重新发明一个与图不一致的开场。

### 首尾帧驱动

`首帧状态 → 差异清单 → 每项差异的物理改变 → 变化逐步收敛 → 尾帧精确落位`

不要重复描述两张静止图而省略中间路径。人物姿态、道具状态、摄影机位置、构图、光线等每项差异都应有可观察变化；无法在时长内合理完成时必须简化或拆镜。

### 尾帧驱动

`与尾帧兼容的前置状态 → 明确动作与镜头路径 → 构图逐渐接近 → 速度下降 → 尾帧位置、姿态、光线和物体状态锁定`

不要让最后一帧通过突变、瞬移或无因变焦实现。

### 多镜头

第一镜无需机械标注0秒。后续切镜只有在新镜头带来空间、时间、信息、状态或动作匹配价值时使用明确切点。跨镜对白、动作或声音要说明是否连续、被遮挡或在切点结束。

## 5. 参考图先行工作流

### 阶段A：首帧设计

先输出导演判断，确认：

- 这张图是视频第0秒、关键帧还是仅作风格参考；
- 下一动作将往哪个方向发展；
- 主体重心和道具当前处于什么未完成状态；
- 摄影机将推进、后拉、平移、摇摄还是保持固定；
- 哪些部位和空间必须完整可见。

图片提示词使用以下结构：

```text
【用途与画幅】
这是后续视频的[首帧/关键帧]，画幅[比例]，优先保证连续运动空间。

【时间与场景】
[年代、季节、时刻、地点、天气、建筑与空间层次]

【主体与开放状态】
[身份不变量、服装、道具、初始姿态、重心、视线、当前接触关系]
[动作尚未完成的可见征兆，以及下一动作的方向]

【构图与摄影】
[机位、角度、主体占比、前中后景、透视、焦点、景深、光向、色彩]
[为手脚、道具、移动路径和摄影机运动保留的画面空间]

【材质与真实度】
[只写当前景别可见的肤质、衣料、建筑或物品细节]

【禁止项】
[身份、结构、构图、肢体、道具、文字和风格的针对性风险]
```

首帧不得把动作写成已经完成；不得让关键手脚或道具被画框裁断；不得用强遮挡封死移动方向；不得让景深和运动路线互相冲突。

### 阶段B：基于实际图片生成视频

用户提供最终参考图后，先以可见事实填写一致性表：

| 维度 | 图片中可见事实 | 视频保持项 | 视频允许变化 | 运动出口 |
|---|---|---|---|---|
| 人物/主体 |  |  |  |  |
| 服装/材质 |  |  |  |  |
| 场景结构 |  |  |  |  |
| 光向与色彩 |  |  |  |  |
| 道具与接触 |  |  |  |  |
| 左右位置 |  |  |  |  |
| 镜头轴线 |  |  |  |  |

如果实际图片与早期设想冲突，以图片事实和用户当前指令为准；在导演判断中说明调整，不把冲突带入可复制提示词。

## 6. 默认交付模板

### 导演判断

- 核心事件：
- 视觉重点：
- 动作因果：
- 运镜选择：
- 最大风险：

### 可直接复制的完整提示词

```text
【核心设定】
[时长、画幅、风格、成像模式、唯一主事件]

【参考职责与全局不变量】
[参考素材分别控制什么；身份、结构、场景、光向、方向和数量]

【初始画面】
[第0秒可见事实、摄影机与主体位置、当前状态]

【连续导演描述】
[按播放顺序写语义节拍；每个节拍包含触发、准备、动作、反馈、停止、终态]

【摄影机与成像】
[运动类型、幅度、速度、目标、停止；透视、景深、焦点、曝光与微扰]

【声音】
[环境、动作、人声、对白、可选配乐的动态关系]

【最终状态与转场接口】
[所有关键主体、物体、摄影机、声音和光线的结束状态]

【严格禁止项】
[按当前任务风险分类的完整限制]
```

模板是信息检查工具，不要求机械保留所有标题。最终文本必须完整自洽，不依赖“同上”或人工拼接。

### 稳定重试版

只在确有高风险时提供。保留唯一主事件、核心视觉结论和终态，优先减少并发人物、交接手、镜头运动、特效或精确文字；说明哪些内容交给后期。

## 7. 审查与稳定降级

1. 提取唯一主事件和三层信息。
2. 建立参考职责表，标记歧义或互相争夺控制权的素材。
3. 检查身份、设备、空间、光向、动作和终态冲突。
4. 找到最早的因果断点，而不是只在结果处增加负面词。
5. 检查动作是否有触发、准备、反馈和停止。
6. 检查运镜是否能写成类型、幅度、速度、目标和终点。
7. 检查声音是否与动作帧和空间距离同步。
8. 命中两项以上高风险组合时，保留导演版并提供减负版。

常见修正：

- 手持随机抖动：明确主趋势，把横漂和高度变化降为人体来源的小幅微扰。
- 首尾帧硬跳：列出差异并为每项补可观察中间变化。
- 参考素材打架：给每份素材分配唯一主职责并明确不采用内容。
- 参数堆叠：把设备名和数值还原成期望透视、景深、稳定度与质感，删除无贡献参数。
- 互动穿模：减少同时入画的手和动作，明确接触点、受力、反馈与退出。
- 声音清单化：补来源、距离、触发、包络和结束后的底噪。
- 禁止项失控：保留详细分类，但删除同义重复和与镜头无关的风险。
